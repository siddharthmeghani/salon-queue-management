# Personal Reflection — Aura Salon Queue Management System

## 1. Project Overview

For this project, I developed the Aura Salon Queue Management System, a web application that helps salons manage customers and reduce waiting time.

The application allows customers to join the queue online, select services, choose a barber, and track their queue position. It also provides separate dashboards for receptionists, barbers, and salon owners.

I used ChatGPT to generate the initial project and downloaded the complete application as a ZIP file. After that, I worked on setting up, testing, and deploying the project.

## 2. My Development Experience

Initially, I was not fully familiar with the complete process of setting up and deploying a React application.

After downloading the project ZIP, I extracted it and opened the folder in Visual Studio Code. I installed the required dependencies using npm and ran the application locally.

I tested the Home page, Join Queue, My Status, Reception dashboard, Barber dashboard, TV Display, and Owner settings.

I also checked features such as token generation, estimated waiting time, barber availability, online queue joining, and English/Gujarati language switching.

ChatGPT helped me understand the steps, but I performed the setup, configuration, testing, and deployment on my laptop.

## 3. Challenges I Faced

One of the main challenges was using Git and GitHub because I was not familiar with all the commands.

Initially, Git was not recognized in my terminal. I installed Git and verified that it was working.

I also accidentally initialized Git in the wrong folder, so I had to correct the repository location.

Another issue occurred when Git displayed an "Author identity unknown" error. I resolved it by configuring my Git username and email.

I also had to understand how Supabase and Vercel work together. I configured the required environment variables and deployed the application.

These problems helped me learn how to troubleshoot errors instead of only following commands.

## 4. What I Learned

Through this project, I learned how to:

- Set up and run a React + Vite project.
- Use Visual Studio Code and terminal commands.
- Install project dependencies using npm.
- Understand a multi-page web application.
- Test customer and staff workflows.
- Use Git for version control.
- Upload source code to GitHub.
- Configure Supabase for shared application data.
- Deploy a website using Vercel.
- Check application functionality after deployment.
- Prepare project documentation.

I also learned that an application working locally does not automatically mean it will work correctly after deployment. Testing the live website is an important step.

## 5. How I Used AI

I used ChatGPT to help generate the initial application and guide me through the development process.

Instead of manually writing the entire application from the beginning, I provided the project requirements and used the generated project as my starting point.

After downloading the files, I used ChatGPT for instructions on running the application, configuring GitHub, setting up Supabase, deploying to Vercel, and testing the features.

I learned that AI can make development faster, but it is still necessary to understand the project, verify its functionality, and solve errors during setup and deployment.

## 6. Testing and Final Result

After deployment, I tested the application using the public Vercel website.

I checked customer registration, token generation, waiting status, Reception operations, Barber operations, TV Display, and Owner settings.

I also tested the English/Gujarati labels and checked that queue information was shared across browser sessions.

The application was successfully deployed, and the main features worked during my testing.

**Live website:** https://salon-queue-management-mu.vercel.app

## 7. Future Improvements

In the future, I would like to improve the application by adding customer notifications, better staff authentication, more detailed reports, and improved queue analytics.

I would also like to learn more about React and Supabase so that I can develop similar applications more independently.

## 8. Conclusion

Overall, this project was a useful learning experience.

The most important things I learned were how to work with an AI-generated project, configure the development environment, troubleshoot errors, use GitHub, and deploy a working web application.

Although ChatGPT helped me throughout the process, I gained practical experience by running the project, testing the features, and completing the deployment myself.

This project improved my confidence in working with modern web development tools.
