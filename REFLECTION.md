# Personal Reflection — Aura Salon Queue Management System

## What the AI Agent Got Wrong

During this project, I used ChatGPT to generate a complete
Salon Queue Management application as a downloadable ZIP file.

One mistake I noticed was that the initial prompts.md template
contained 12 separate suggested development prompts. However,
I had generated the complete application at once instead of
using those individual prompts.

## How I Noticed the Mistake

While reviewing the project documentation and submission
checklist, I noticed that the suggested prompt history did
not accurately represent my actual development process.

## How I Fixed It

I clarified to ChatGPT that I had generated the complete
project and downloaded it as a ZIP file. I requested an
updated prompt log that reflected my actual workflow,
including project setup, testing, Supabase configuration,
GitHub upload, and Vercel deployment.

I also made sure that reconstructed prompts were clearly
identified instead of presenting them as exact original
messages.

## What I Learned

This experience taught me that AI-generated documentation
should always be reviewed and verified. AI can speed up
development, but clear instructions and human verification
are necessary to ensure accurate results.

I also gained practical experience with React, Git, GitHub,
Supabase, Vercel, and application testing.
